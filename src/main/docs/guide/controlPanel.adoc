The `micronaut-langchain4j-control-panel` module adds an *AI* section to the https://micronaut-projects.github.io/micronaut-control-panel/latest/guide/[Micronaut Control Panel]. It lists the chat, embedding, image and scoring models, the embedding stores, the AI services and the tools of the application, and has a chat to send messages to any chat model:

dependency:io.micronaut.langchain4j:micronaut-langchain4j-control-panel[scope="developmentOnly"]

dependency:io.micronaut.controlpanel:micronaut-control-panel-ui[scope="developmentOnly"]

The Control Panel is only enabled in the `dev` and `test` environments by default. Sending a message to a model costs tokens, so the chat requires write access to the Control Panel. Disable the panel with:

[configuration]
----
micronaut.control-panel.panels.langchain4j.enabled: false
----
