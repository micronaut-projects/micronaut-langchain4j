LangChain4j implements AI services and agents with `java.lang.reflect.Proxy` and reads their annotations (`@SystemMessage`, `@UserMessage`, `@V`, `@Agent`, `@SequenceAgent`, `@Output`, ...), parameters and return types reflectively. Micronaut LangChain4j takes care of what this requires, so applications declare no reflection configuration:

* *Tools* are not discovered reflectively. The `ToolSpecification` of each `@Tool` method is built from the compile-time metadata of the method, and the method is invoked through its Micronaut `ExecutableMethod`, so tool classes need no reflection at all.
* *GraalVM Native Image*: `micronaut-langchain4j-processor` writes the native image metadata (`META-INF/native-image/io.micronaut.langchain4j/<type>/reachability-metadata.json`) of every `@AiService`, every `@AgenticService` and every type declaring `@Agent`, workflow (`@SequenceAgent`, `@ParallelAgent`, `@LoopAgent`, ...) or other declarative agent (`@HumanInTheLoop`, `@A2AClientAgent`, `@McpClientAgent`, `@RegistryAgent`) methods: the reflective access to their methods, and the proxy classes LangChain4j creates for them.
* *Python*: `@AiService`, `@AgenticService` and the LangChain4j annotations imply the `@AllowsReflection` hint (`io.micronaut.core.annotation`), so the Python compiler copies the annotations onto the Java types it generates. Neither `@AllowsReflection` nor the `micronaut.introspection.allow-reflection` compiler option is needed. The hint for the LangChain4j annotations is added by `micronaut-langchain4j-processor`, which must be on the compile classpath of the Python sources.

NOTE: The JSON mapping of the structured outputs of AI services (the POJOs or records they return) and of POJO tool parameters is still done by LangChain4j with Jackson, which reads these classes reflectively: in a native image they need reflection metadata, for example with `@ReflectiveAccess` or `@Introspected` and Micronaut's GraalVM support.

NOTE: The processor must be on the annotation processor path of the classes declaring the services and agents (`annotationProcessor("io.micronaut.langchain4j:micronaut-langchain4j-processor")` in Gradle) for the native image metadata to be generated.
