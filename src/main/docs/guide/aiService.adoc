== Reactive Streaming Support

If you want your `@AiService` to return a `Flux<String>` for streaming responses, you need to:

1. Add the https://github.com/langchain4j/langchain4j-spring/tree/main/langchain4j-reactor[`langchain4j-reactor`] dependency:

dependency:dev.langchain4j:langchain4j-reactor[]

2. Configure a streaming chat model in your configuration (instead of or in addition to the regular chat model):

.Example Configuration
[configuration]
----
langchain4j.open-ai.streaming-chat-model.model-name: gpt-4o
langchain4j.open-ai.streaming-chat-model.temperature: 0.3
----

You can then define an `@AiService` that returns a `Flux<String>`:
