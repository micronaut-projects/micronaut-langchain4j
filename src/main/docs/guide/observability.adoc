=== Micrometer

To record the https://opentelemetry.io/docs/specs/semconv/gen-ai/gen-ai-metrics/[OpenTelemetry GenAI metrics] of the chat models with https://micronaut-projects.github.io/micronaut-micrometer/latest/guide/[Micronaut Micrometer], add the following dependency:

dependency:io.micronaut.langchain4j:micronaut-langchain4j-micrometer[]

When there is a `MeterRegistry` bean, LangChain4j's `MicrometerMetricsChatModelListener` is registered. It records:

* `gen_ai.client.token.usage` - the input and output tokens, tagged with the provider, the operation, the request and response model names and the token type.
* `gen_ai.client.operation.duration` - the duration of the chat model requests.

When there is also an `ObservationRegistry` bean (for example with `micronaut-micrometer-observation`) and `dev.langchain4j:langchain4j-observation` is on the classpath, LangChain4j's `ObservationChatModelListener` is registered instead. It records each chat model request as a Micrometer observation, which produces the same metrics and, with a tracing bridge, spans.

Set `langchain4j.micrometer.enabled` to `false` to disable these listeners.

=== AI Service Events

The AI services publish LangChain4j's AI service events as Micronaut application events. Observe them with `@EventListener` methods or `ApplicationEventListener` beans:

snippet::example.micronaut.aiservice.events.AiServiceAuditor[source="main"]

<1> An event listener method receives the events of every AI service.
<2> The invocation context identifies the AI service, the method and the invocation, which correlates the events of one invocation.
<3> Each tool execution produces an event with the request and the result of the tool.

The following events are published: `AiServiceStartedEvent`, `AiServiceRequestIssuedEvent`, `AiServiceResponseReceivedEvent`, `AiServiceCompletedEvent`, `AiServiceErrorEvent`, `InputGuardrailExecutedEvent`, `OutputGuardrailExecutedEvent`, `ToolExecutedEvent` and `ToolCompensatedEvent` (all in the `dev.langchain4j.observability.api.event` package). A listener of a super type, such as `AiServiceEvent`, receives all of them. An event type is only published when there is a listener for it.

Beans implementing LangChain4j's `AiServiceListener` (for example `AiServiceCompletedListener`) are also registered with every AI service.
