https://github.com/tjake/Jlama[Jlama] runs the models in the JVM, without a model server. Add the following dependency:

dependency:io.micronaut.langchain4j:micronaut-langchain4j-jlama[]

Then configure the model, which Jlama downloads from Hugging Face into its working directory on the first use:

.Example Configuration
[configuration]
----
langchain4j:
  jlama:
    chat-model:
      model-name: tjake/Llama-3.2-1B-Instruct-JQ4
    embedding-model:
      model-name: intfloat/e5-small-v2
----

NOTE: Jlama uses the incubating Vector API of the JDK: run the application with `--add-modules jdk.incubator.vector --enable-preview`. Jlama is not supported in a GraalVM native image.
