Add the following dependency to use the Jina models:

dependency:io.micronaut.langchain4j:micronaut-langchain4j-jina[]

.Example Configuration
[configuration]
----
langchain4j:
  jina:
    api-key: ${JINA_API_KEY}
    scoring-model:
      model-name: jina-reranker-v2-base-multilingual
    embedding-model:
      model-name: jina-embeddings-v3
----
